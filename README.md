# DroneRadar

ドローン関連の情報を横断収集する macOS 用ダッシュボード。`DroneRadar.app` をダブルクリックすると
ローカルサーバーが立ち上がり、ブラウザにダッシュボードが開きます。

追加インストールは不要です。macOS 標準の `/usr/bin/python3` と標準ライブラリだけで動きます。
外部APIはすべて無料・APIキー不要のものだけを使っています。

## インストール（アプリケーションフォルダに入れる）

```bash
./tools_install.sh
```

コードをバンドル内に取り込んだ自己完結版を組み立てて `/Applications/DroneRadar.app` に置きます。
以後は Launchpad や Finder のアプリケーションから起動できます。データは
`~/Library/Application Support/DroneRadar/` に移り、初回だけ既存の `data/` を引き継ぎます
（/Applications 内のアプリが自分のバンドル内に書き込むべきではないため）。
**コードを変更したらこのスクリプトを実行し直してください** — インストール版はバンドル内のコピーで動きます。

## 起動（開発用・このフォルダから）

```bash
open "DroneRadar.app"
```

こちらは隣の `droneradar/` を直接読むので、編集がそのまま反映されます（データは `data/`）。

ターミナルから直接動かす場合:

```bash
cd "DroneRadar" && /usr/bin/python3 -m droneradar.server
```

既に起動している状態でもう一度アプリを開くと、二重起動せずブラウザだけが開きます。
ポートを変えたいときは `DRONERADAR_PORT=9000` を設定してください。

## 画面

| 領域 | 内容 |
|---|---|
| 上部 | 全文絞り込み、期間（24時間〜すべて）、言語、**画像あり**トグル、並び替え、更新ボタン |
| グラフ | 「グラフを隠す」で折りたたみ可（設定はブラウザに記憶されます） |
| 左 | 畳んだジャンル一覧。カーソルを載せると開き、件数も出ます（本文は動きません） |
| 中央上 | 重要ニュースの電光掲示板 / 都道府県マップ / 世界マップ / 動画の連続再生 |
| 中央下 | 左＝主要ニュース（固定）、右＝ジャンルが自動でめくれる枠 |
| 右 | リアルタイムSNS、ライブレーダー、ドローン関連株 |

全体がスクロールなしで1画面に収まり、上が地図と動画（約6割）、下がニュース（約4割）です。
ニュース欄の段数は**ウィンドウの高さから毎回計算**して余白が出ないように詰めるので、
画面が大きいほど多くの見出しが並びます（1121pxの画面で74件）。
グラフは「グラフを隠す」で畳めば、そのぶん見出しが増えます。
左のジャンル別件数はカーソルを載せたときだけ表示します。

- **地図の集計**: 1記事は「主に扱っている1か所」だけで数えます。言及した国すべてで数えると、
  国内制度の記事が米国と中国にも計上されるなど、世界地図が実態より大きく出ます。
- **地図**: 日本地図と世界地図を常時併記します。日本側は都道府県・主要都市名、世界側は国名から
  判定し、どちらもクリックでその地域に絞り込めます。沖縄は左下のインセットに配置しています。
  3つのパネルは同じ高さに揃え、地図は枠いっぱいまで拡大されます。
- **スポットライト**: 約4秒ごとに記事を1件ずつ選び、その地域に**レーダーのリングを3連で飛ばして**
  塗りごと光らせ、海の上に重ねた帯にサムネイル・見出し・本文を出します（クリックで記事が開きます）。
  小さな県では枠線を光らせるだけでは見えないため、リングで位置を示しています。
  ピングの約1秒後にその地域へズームインし、1.5秒見せてから元の縮尺に戻ります
  （viewBoxはCSSで補間できないので手動のイージングです）。
  帯は地図が実際に描画されている下端の直下から panel 下端までを使い、日本地図と世界地図で
  高さを揃えてあります。中身は地域・媒体・時刻の1行＋見出し＋本文で、本文が残りの高さを
  埋めるので枠だけ広くて中身が薄い状態になりません（本文が無い記事は見出しを6行まで広げます）。
  日本地図側は列が狭いためサムネイルは出しません。
- **配色**: 全体をダークネイビー基調にし、背景に淡いブルーのグラデーションを敷いて
  面ごとに明度差を付けています（単色の板に見えないように）。強調色はシアン寄りの青1色です。
  地図は濃い海の色に薄い経緯線グリッドを重ねて、空いた海域が余白ではなく水面に見えるように
  しています。地図自体は上端に寄せ、余る高さは下の見出し帯が使います。
  分類の凡例は左のサイドバーの色チップが兼ねるので、地図の下には置いていません。
- **接続が切れたとき**: サーバーを終了してタブだけ残すと定期取得が失敗し続けます。
  取得は失敗しても例外を投げずに諦め、右上のランプが赤（接続なし）になります。
- **分類の配色**: 分類ごとに色を割り当て、地図の塗り・レーダー・左の畳んだ一覧のチップまで
  同じ色を使います。地図の色は「その地域で最も多い分類」、濃さは件数です。
- **電光掲示板**: 最上段は重要ニュースを横に流し続けます。直近24時間のニュース系分類から
  候補を60件ぶん取り、18件ずつの窓を3分ごとに入れ替えるので同じ見出しが繰り返しません
  （開発・研究・コミュニティは対象外）。マウスを載せると停止し、クリックで記事が開きます。
- **2枠構成**: 左は主要ニュース固定、右はジャンルが8秒ごとに自動で切り替わります。
  見出し横の丸をクリックするとそのジャンルに固定でき、もう一度押すと自動送りに戻ります。
  行の中は3段×複数列のコンパクトなリストで、矢印か横スクロールで送れます。
  「時系列」ボタンで単純な新着順の一覧にも切り替えられます。
- **同一ニュースのまとめ**: 媒体が違っても内容が同じ記事は1件にまとめ、`4媒体` のような
  バッジで束ねた数を出します。見出しの文字の重なりに加えて、固有名詞・数字・略語のうち
  その時点で珍しいものを突き合わせ、さらに同日・同じ国の記事は具体語3つ以上の一致でまとめます
  （「モスクワに無人機600機」と「モスクワ方面に大規模無人機攻撃」のような言い換えを拾うため）。
- **再生中の同期**: 埋め込みプレイヤーは自分でプレイリストを進むため、YouTube IFrame API から
  現在の動画IDを取得してタイトルを合わせています。「このあと」の一覧も再生の進行と時間で
  入れ替わるので、同じ数本が並び続けません。
- **同じ動画を繰り返さない工夫**: 投稿者ごとに交互に並べ替えて1チャンネルが列を占めないようにし、
  再生開始位置は収集のたびに加えて**ページを開くたびにも**ずらします（位置をブラウザに保存）。
  プレイリストが一周して先頭に戻ったのを検知したら、次の25本で組み直します。
- **再生できない動画**: 投稿者が埋め込みを禁止している動画（エラー101/150）に当たると
  「この動画は再生できません」で連鎖が止まります。IFrame API のエラーを拾って次の動画へ送り、
  その動画IDはブラウザに記録して以後キューに入れません。
- **動画**: 一覧はジャンル送りの1つとして他の分類と同じように流れます。それとは別に、
  地図の右に「連続再生」枠が常設で、無音の自動再生から次の動画へ勝手に進みます
  （YouTubeの `playlist` パラメータで繋いでいるので、追加のスクリプトは要りません）。
  下に「このあと」の数件を出していて、クリックするとそこから再生し直します。
  なお、このプレイヤーはHTML側に置いた固定要素です。iframeは作り直しても移動しても
  ブラウザが読み込み直すため、描画のたびに生成していると自動再生が毎回止まります。
- **見出しの整形**: `【ドローン空撮4K】` のような装飾や末尾のサイト名を落とし、自然な区切りで
  詰めて表示します。`【速報】` など意味のある見出しは残します。元のタイトルはホバーで出ます。
- **戦争・軍事の切り分け**: ウクライナ関連などの軍事報道は本文から判定して「防衛・軍事」に
  振り分けます（ソースではなく内容で判定）。
- **イベントの切り分け**: ショー・レース・展示会・放映などの語を含む記事は「イベント・大会」へ。
  軍事判定を先に通すので、航空ショーでの攻撃といった記事はイベントではなく防衛に入ります。
- **重要度**: 国土交通省・航空局・航空法・型式認証・レベル4といった語を含む記事を「重要」、
  全国規模と判定した記事を「全国」として強調します。
- **報道媒体数**: 見出しの類似度で同一トピックをまとめ、複数媒体が扱った話題を上位に出します。
- **日別グラフ**: 棒をクリックするとその日だけに絞り込みます（もう一度押すと解除）。
  グラフ自体は絞り込み中も全期間を表示し続けます。
- **英語記事の翻訳**: 英語のタイトルと要約を日本語に訳して表示し、原題を下に小さく併記します。
  訳文の頭には判定した国名バッジ（例: `米国`）が付きます。訳文はキャッシュされるので、
  同じ記事に二度分の通信はかかりません。GitHubはリポジトリ名を残して説明文だけを訳します。
- **ライブレーダー**: 右カラムの円形表示。**角度が記事の分類、中心からの距離が新しさ**
  で、直近6時間に入ってきたものが実際にプロットされます。ビームが通過した瞬間にその方角のブリップが
  光ります（JSのタイマーではなく、掃引と同じ周期のCSSアニメーションに方位ぶんの負のディレイを
  与えて位相を合わせているのでズレません）。新しい3件には見出しが付き、クリックで元記事が開きます。
- **新着の見せ方**: 収集で記事が増えると「新着 N件」が出て、新しいカードはスライドインします。
  SNS欄は先頭を見ているときだけ自動で最新に追従します。

### YouTube検索

Data API はキーが必要なので、検索結果ページに埋め込まれた `ytInitialData` から
タイトル・チャンネル名・投稿時期・再生数・サムネイルを読み出しています（`sp=CAI%3D` で新着順）。
投稿時期は「3 週間前」のような相対表記しか出ないため、それを解釈して日時に直しています。

### 翻訳

Google の翻訳エンドポイント（APIキー不要）を主系、MyMemory を予備系に使います。
1件ずつ翻訳しています — このエンドポイントは `q` を複数渡しても最初の1件しか訳さず、
改行でまとめると行数がずれて記事と訳文の対応が壊れるためです。
1回の収集あたりの上限は `translate_budget`（既定400件）です。

**海外** — DroneDJ、DroneLife、sUAS News、The Drone Girl、UAS Vision、New Atlas、

**規制** — EASA（公式RSS）、国土交通省・FAA（後述の site: 検索）
**研究・開発** — arXiv、GitHub、ArduPilot、PX4、Hacker News
**空撮・FPV** — Google ニュース検索、r/fpv、r/dronephotography
**イベント・大会** — ドローンショー / レース / 展示会 / 見本市の検索（本文判定で他分類からも振り分け）。
ドローンショーのテレビ放映や航空ショーもここに入ります。
**防衛・軍事** — 国内外の軍事ドローン検索（本文判定で他分類からも振り分け）
**動画** — DJI、Autel、DroneDJ、Parrot、Drone Racing League、Rotor Riot、UAV Futures（チャンネルRSS）と、
**YouTube検索**（ドローン空撮 / FPV / ドローンショー / ニュース / drone footage）。
検索側は個人投稿を拾うためのもので、チャンネルRSSでは出てこない空撮やFPV映像が入ります。
検索は本文に「ドローン」が出るだけで拾ってしまうため、BGM・作業用・カラオケ・ASMR等は除外し、
さらに検索経由の動画は見出しに空撮/FPV/4K/ニュース/レース等が含まれるものだけを残しています。
**検索** — Google ニュース RSS（日本語・英語・`site:`指定）

### RSSが無いサイトの扱い

- **ドローンジャーナル**（インプレス）は RSS が提供されていないため、記事一覧ページ専用の
  スクレイパで取得しています。タイトル・画像・日付・タグを取得します。
- **国土交通省・FAA・DJI** などは RSS が廃止済みのため、Google ニュースの
  `site:mlit.go.jp ドローン` のような検索に自動で切り替えて収集しています。

### リアルタイムSNS

X（旧Twitter）は無料の公開読み取りAPIが廃止されており、公開Nitterミラーもすべて 403 でした。
そのため **Yahoo!リアルタイム検索** 経由でX投稿を取得しています（本文・投稿者・時刻・
RT/いいね数・アイコン付き）。あわせて Mastodon（mastodon.social / mstdn.jp / fedibird.com）、
Reddit、Hacker News を取得し、60秒ごとに更新します。

### 株価

Yahoo Finance の無料JSON（キー不要）を主系、Google Finance のHTMLを予備系にして5分ごとに更新します。
どちらも失敗した場合は直前の値を薄く表示し、`取得失敗` を出します。
銘柄は AeroVironment / Kratos / Red Cat / Ondas / Unusual Machines / Draganfly / AgEagle /
EHang / Joby / Archer / ACSL(6232) / テラドローン(278A)。

株価パネルは右カラムに収まる4銘柄ぶんの高さに固定し、6秒ごとにページを送ります
（カーソルを載せている間は止まります）。

> Yahoo Finance はネットワークによっては 429（レート制限）を返すことがあります。
> その場合は自動的に Google Finance 側で取得します。

## ソースの追加

ソース管理画面の入力欄に入れるだけです。

- **URL** → RSS を自動検出して登録。見つからなければ Google ニュースの `site:` 検索に自動で切替
- **YouTubeのチャンネルURL** → そのチャンネルの動画フィードを登録
- **URLでない文字列** → キーワード検索として登録

各ソースは個別に有効・無効を切り替えられます。取得件数と最終取得時刻、失敗時のエラーも表示されます。

## 更新間隔

| 対象 | 既定 | 設定キー |
|---|---|---|
| 記事・動画 | 15分 | `interval_minutes` |
| 翻訳の上限 | 400件/回 | `translate_budget` |
| SNS | 60秒 | `social_seconds` |
| 株価 | 5分 | `stocks_minutes` |

`data/config.json` で変更できます。`exclude` に文字列を並べると、それを含む記事を除外します。

## 既知の制限

- **Google ニュース経由の記事には画像が付きません。** リンクが不透明なリダイレクトトークンで、
  発行元URLに解決できないためです（batchexecute経由の解決も試しましたが現在は塞がれています）。
  直接RSSで取得している記事は100%画像が付きます。画像付きだけを見たいときは上部の
  「画像あり」トグルを使ってください。同一トピックが直接RSS側にもある場合は、そちらの画像を流用します。
- Reddit は短時間に何度も取得すると 429 を返します。次回の収集で自動的に復帰します。
- ドローンジャーナルと Yahoo!リアルタイム検索はHTML構造に依存しています。先方の改修で
  取得できなくなった場合は、ソース管理画面にエラーが表示されます。

## データの出典とライセンス

地図はどちらも **Natural Earth**（`ne_10m_admin_1_states_provinces` と
`ne_110m_admin_0_countries`）から生成しています。Natural Earth はパブリックドメインで、
出典表記も利用報告も不要です。都道府県コードは `iso_3166_2`（JP-01〜47、JISの番号と一致）、
日本語名は `name_ja` をそのまま使っています。

以前は日本地図に国土地理院「地球地図日本」由来のデータを使っていましたが、非営利でも出典明記が
必須で営利利用には著作権者への報告も要るため、条件の付かない Natural Earth に置き換えました。

記事・SNS・株価・翻訳は各サービスから取得しているだけで、このリポジトリには含みません。

## 音源

新着通知の効果音 `droneradar/web/sonar-ping.wav` は、Joseph SARDIN 氏による
アクティブソナーのフィールド録音（BigSoundBank「Sonar #1」, CC0 / パブリック
ドメイン相当、帰属表示は不要）から、1回ぶんの打点を切り出したものです。
1040Hz、3.5秒間隔で鳴っている録音の 3.50秒地点から 3.40秒を抜き、頭に3msの
フェードイン、末尾に250msのフェードアウトを掛けて −3dBFS に正規化しています。

出典: https://bigsoundbank.com/sonar-s1416.html

## 別の端末で表示する（Fire タブレット・Fire TV など）

サーバは既定では 127.0.0.1 にだけ待ち受けるので、同じ Mac からしか開けません。
同じ Wi-Fi の別端末に映したい場合だけ、環境変数で解放します。

    DRONERADAR_LAN=1 open /Applications/DroneRadar.app

起動時のログに `同じネットワークから → http://192.168.x.x:8783/` が出るので、
その URL を端末側のブラウザ（Fire なら Silk）で開きます。

既定で閉じてあるのは、記事の閲覧だけでなく、ソースの追加や設定変更の
エンドポイントも同時に開いてしまうためです。信頼できるネットワークでのみ
使ってください。
