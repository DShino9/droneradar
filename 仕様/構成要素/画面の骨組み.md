## 依存の向き

```
state ← util ← 各機能モジュール ← main
```

`state.js` は何も import しない。`main.js` だけが全モジュールを import する。

色の解決だけは例外的な形になっている。`catColor()` は `state.js` にあるが、
どの分類がどのグループかを知るのは `genre.js` である。`state.js` が
`genre.js` を import すると葉でなくなるため、`main.js` が起動時に
`setGroupResolver(groupOf)` で注入する。

葉のモジュールが全体再描画を必要とする場合、`main` を import すると
循環するため、`state.js` のフック表を経由する。

```js
// state.js
const hooks = { renderAll: () => {}, renderCards: () => {}, announceNew: () => {} };
// 関数を持つモジュールが自分で登録する
hooks.renderCards = (items) => renderCards(items);
```

`api → cards → api` の循環は実際に起きた。`api.js` が `announceNew` を
直接 import していたためで、フック経由に変えて解消した。



## ジャンル（17分類 / 7グループ）

分類は 17 のまま、色は 7 グループが持つ。17 色は地図の塗りや直径 3px の
レーダー輝点では見分けられず、凡例が読む価値を失っていたため。グループ内の
区別はアイコンが担う。グループ定義は `web/js/genre.js`。

| グループ | 色 | 含む分類 |
|---|---|---|
| ニュース | `#4cc4ff` | 国内ニュース、海外ニュース |
| 防衛・安全 | `#ff6b7d` | 防衛・軍事、対ドローン・安全 |
| 規制・制度 | `#ffb445` | 規制・制度 |
| 現場・運用 | `#5fdc86` | 産業活用、測量・点検、災害・救助、eVTOL・空飛ぶクルマ |
| 製品・技術 | `#ac92ff` | 製品・新機種、研究・論文、開発・OSS |
| ビジネス | `#ff9366` | ビジネス・投資 |
| 空撮・催事 | `#f77fc0` | 空撮・FPV、イベント・大会、コミュニティ、動画 |

絞り込みの粒度は落としていない。サイドバーはグループ7行を出し、開くと
その下に分類が並ぶ。`S.filter.group` だけならグループ全体、`S.filter.cat`
があればその分類だけを表示する。



アイコンの出る場所は、サイドバーのグループ行、記事カード／タイルのメタ行、
ジャンル列の見出し、ジャンル送りのチップ、地図キャプション、地図のピン。



## 国旗

国コードは ISO-3166 alpha-2 なので、国旗は表を持たず符号から導く
（`flagOf`: 各文字を Regional Indicator に写す）。Windows には国旗の
グリフが無く2文字のまま表示されるが、それでも読めるラベルではある。



## 動画が最後で止まる

停滞監視が**再生終了（state 0）を「正常」として扱っていた**。埋め込みは
自分のプレイリストを勝手に進むから、という理屈で——実際そのとおりだが、
**最後の1本まで**の話。そこで YouTube は停止し、リプレイボタンと関連動画の
一覧を出す。誰も次を促さないので、枠は 4:21 / 4:21 のまま固まる。

終了が2.5秒続いたら次の一巡を取りに行く（プレイリストが先頭に戻った
ときと同じ処理）。一時停止は従来どおり放置する——あれは読み手の意思。



## リモコン操作

Fire TV には十字キー・決定・戻るしかない。1段階で扱うと60件並ぶ行が破綻するので2段階にした。**全OSで同じ挙動**、キーボードの矢印キー・Enter・Escape も同一コードで動くので、デスクトップがそのまま検証台になる。

- **第1段階** — 左右でツール間を移動（サイドバー→掲示板→日本地図→世界地図→動画→記事→カレンダー→レーダー→SNS→株価）
- **第2段階** — 決定で入り、上下左右で項目間を移動、決定で開く、戻るでツールへ、もう一度戻るで解除

上下は添字送りではなく画面上の行で判定する。記事欄は5段の列組みなので、添字だと「下」で横に飛ぶ。空のパネルは飛ばし、行の端で左右に出ると隣のパネルへ移る。ポインタを触ると解除される。
