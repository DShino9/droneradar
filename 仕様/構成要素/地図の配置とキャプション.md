# DroneRadar — 地図の配置とキャプション

[仕様書.md](../../仕様書.md) の構成要素。**地図・動画の帯の寸法、地図の下に出る記事（キャプション）の置き方、縦長ウィンドウでの組み替え。**

| | |
|---|---|
| 受け持つ | 列幅・地図の天井・キャプションの位置と行数・狭い幅での配置 |
| 受け持たない | どの記事を出すか（[地図のスポットライト](地図のスポットライト.md)） |
| 実体 | `droneradar/web/js/maps.js`、`droneradar/web/style.css` |
| 開くのはこんな時 | キャプションが切れる・消える／地図の下が隠れる／狭い画面で崩れる |

## キャプションの高さと行数

キャプションは「地図の下に余った分だけ」の可変高だった。帯を固定高に
してからは、この前提で書かれた指定が3か所で悪さをした。

**1. 行数が3行固定。** 枠は約96px、うち余白22px・媒体行26pxで、
本文に使えるのは48px。15.5px×1.45の行が2行分の高さに3行を入れる指定
だったので、はみ出した分が枠に切られて**行の途中で文字が切断**された。
省略ではなく描画の失敗に見える。

→ 枠の高さから入る行数を計算して `-webkit-line-clamp` に入れる。
クランプなら切れ目に「…」が付き、行の途中では切れない。

**2. 媒体行が縮んで消えた。** flex 列の既定では縮むので、見出しが2行に
なると媒体行が 22px→13px に潰れ、国旗と国名が切れて見えなくなった。
見出しはクランプで1行譲れるが、この行は1行かゼロかしかない。
→ `flex: none`。

**3. 画像も要約も無い記事は見出しを18〜23pxで組んでいた。** 可変高だった
頃、そうしないと箱が3分の2空いたため。固定高では23pxの2行が入らず、
ただはみ出す。→ 一律15.5px、行数は高さから。

枠は 96〜124px（下限＝余白＋媒体行＋2行、上限＝世界地図が横長で
上に寄るため、放っておくとキャプションがパネルの半分を占める）。



## 地図の列幅

日本の列は 228px（狭幅時 132px）の固定だった。日本列島は縦長なので、
列を広げても島の横に余白が増えるだけ——という理由づけは地図としては
正しいが、**その列はキャプション（その地域の記事）も載せている**。
228pxでは見出しが1行4語、132pxでは3文字になる。

地図に幅は要らないが、その下の文には要る。両地図を同じ 1fr にした。

| | 旧 | 新 |
|---|---:|---:|
| 日本パネル（1920幅） | 228px | **403px** |
| 世界パネル（1920幅） | 523px | **403px** |
| 日本パネル（1280幅） | 132px | **252px** |

日本の列を広げると地図自身も伸びようとする（369px幅なら420px高）ので、
帯の上限 344px で頭を打たせる。**幅はキャプションのためであって
地図のためではない**ので、譲るのは地図。

## 地図とキャプションの重なり

キャプションはパネル下端に固定した重ね置き。世界地図では問題にならない
——横長なので枠の上に寄って描かれ、キャプションは元々空いていた海の上に
載る。日本は縦長で枠を埋め切るので、**下3分の1が常に隠れた。九州と四国が
一度も画面に出ない。**

地図に天井を与える：パネルの高さから、キャプションの帯と枠の内側余白を
引いた分。天井はパネルから決めるので、地図自身の描画高から決めると起きる
「毎回少しずつ縮む」は起きない。

| | 変更前 | 変更後 |
|---|---:|---:|
| 日本地図に隠れていた高さ | 約100px | **0** |
| 日本地図の大きさ（1920幅） | 枠いっぱい | 162×184（全体が見える） |

縦長の地図を高さで縛る以上、幅は余る。南が無い地図は日本地図ではないので
これは妥当な交換だが、余白の使い道は別途検討の余地がある。

**キャプションの位置は地図ごとに決める。** 以前は両地図の高いほうに揃えて
いたので、横長で低く描かれる世界地図の下に空白の帯ができた。それぞれ自分の
地図の直下から始め、下端はパネルの底で揃う——見えるのは底の線の方。
結果、世界側のキャプションは96→178pxになり、空白が本文に変わった。

## 地図キャプションの置き場所

キャプション（地図の下に出る記事）は絶対配置で、`top` を JS が
「地図の自然な高さ + 12px」に設定していた。パネルは地図が欲しがる高さより
必ず高い、という前提の作り。

帯を302pxに縮めた時点でその前提が崩れた。地図が枠を埋め切り、キャプションの
`top` が枠の下端を越え、`top` と `bottom: 8px` の間で引き伸ばされる要素
なので**高さが負になって記事が消えた**。

`top` に上限を付けた。キャプションは常にパネル下端に84pxの帯を確保し、
譲るのは地図の側。



## 縦長のウィンドウ

幅1200px以下では、**地図2枚を横に並べたまま、動画を下段に回す**。

以前は1列に畳んでいたが、それは幅を捨てる配置だった。日本地図は縦横比が
0.88、地球儀は正方形なので、全幅のパネルは中央に小さな地図があるだけの
余白になり、しかもパネルは無駄に高い。

| | 旧（1050px幅） | 新 |
|---|---|---|
| 地図の配置 | 1列・全幅610px | **2列・各300px** |
| 球の直径 | — | 242px |
| キャプションの重なり | **75px** | **0px** |

境界を1100→1200pxにしたのは、その間だと3列が各206pxになり、地図にも
その下の文にも狭すぎるため。820px以下は分ける幅が無いので1列。

**地図パネルに最低高（380px）を与える。** 広い配置では帯の上限が高さを
決めているが、縦長配置には上限が無く、`height:100%` のSVGが内容で決まる
箱に入ると潰れる——166pxの箱に73pxの地球儀になっていた。


余白の使い道は [課題/0005](../../課題/0005-縦長の日本地図の横に余る幅の使い道.md)（たね）。
