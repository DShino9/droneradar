### ジャンルの判定

（ジャンルの色とグループは画面側 → [画面の骨組み](画面の骨組み.md#ジャンル17分類--7グループ)）

ジャンルはソース定義が持つ値を起点に、本文から再判定する。判定順序が重要で、
上から順に最初に当たったものを採る。



1. `aam` — 空飛ぶクルマ、eVTOL、エアタクシー
2. `defense` — 軍事語。「迎撃」を含む戦争報道を対ドローンに取られないよう先に置く
3. `security` — 対ドローン、侵入、無許可飛行、書類送検
4. `disaster` — 災害、救助、捜索、消防
5. `events` — 開催、展示会、レース、ショー
6. `survey` — 測量、点検、インフラ、点群
7. `industry` — 配送、農薬散布、国家資格

再判定の対象は `jp_news` / `world_news` / `business` / `hobby` のみ。
`research` や `dev` は既に内容を言い当てているので触らない。



## 拒まれるソースの予備経路

5社のフィードは、この Mac には答えて毎時の収集機には答えない。Cloudflare は
**アドレスで**データセンターを弾くので、UA をどう変えても通らない。同じ記事を
Google News は索引していて誰にでも答えるため、ソースに `fallback` を持たせ、
**直リンクが失敗したときだけ**そちらへ回す。

置き換えではなく予備。直リンクが通る機械では直リンクが使われる（速く、
内容も濃い）。検索経由で取れた回は `via="search"` を残す——直リンクが
死んでいるのに緑の正常表示になるのは、知らないままでいたくない類の嘘なので。

Reddit の分は Google News が Reddit を索引していないため回復できない。
Reddit の定義は5本。2026-09-26 01:29Z の公開版の回では4本が HTTP 429、r/drones だけ通った（2026-09-26 数えた）。
数え方：data ブランチの `sources.json` で `error` が入っているもの。同じ回に直リンクが落ちて
`via="search"` で予備に回ったのは4本（dronetribune・dronelife・suasnews・dronegirl）。
`fallback` を持つ5本のうち verticalmag はこの回は直リンクで通った。
つまりこの回に GitHub の IP から直リンクで取れなかったのは **8本**（予備で回復4＋Reddit 4）。

**`merge_builtins` の項目一覧に `fallback` を入れること。** 保存済みの
定義は決め打ちの一覧の項目しか更新しないので、後から加えた項目は
保存側に届かない。実際これを忘れて一度公開し、コードは正しいのに
データが一世代前で不調件数が動かなかった。同じ穴は core/collector.js の
`OWNED` にもある。

## ソースの穴（第3次追加で埋めたもの）

87本の時点で欠けていたのは細かい隅ではなく、主題そのものだった。

| 欠けていた領域 | 追加 |
|---|---|
| 国家資格・機体認証 | 日本の運用者全員が通る制度が1本も無かった |
| 電波法・無線局 | 航空法の側は拾えていたが、電波の側が無かった |
| 事故・墜落・書類送検 | 安全情報が皆無 |
| 農業ドローン | 混成クエリ1本の一部だけ |
| 自治体の実証実験 | 日本の実用化の主戦場 |
| 水中・港湾 | 無し |
| JUIDA・官民協議会 | 無し |
| Commercial UAV News / Unmanned Systems Technology | 業界大手2誌。RSS が停止している |
| Skydio / Zipline / Wing / Anduril | DJI 規制の受け皿になっている米メーカー |
| BVLOS・回廊・Part 108 | 制度運用の核心 |

フィードが停止・空のサイト（Commercial UAV News、Unmanned Systems
Technology、JUIDA、Skydio）は Google News の `site:` または名前検索で拾う。
MLIT と FAA に既に使っていた手と同じ。



## HTTP API

すべて 127.0.0.1 のみ。認証なし。

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/state` | 記事、ソース、カテゴリ、設定の一括取得 |
| GET | `/api/status` | 収集の進行状況とログ |
| GET | `/api/social` | SNS 投稿 |
| GET | `/api/stocks` | 株価 |
| GET | `/img?u=` | 画像のプロキシ（キャッシュ付） |
| POST | `/api/refresh` | 収集を今すぐ実行 |
| POST | `/api/sources/add` | ソース追加。RSS 自動検出 → www 補完 → Google News の `site:` 検索の順に試す |
| POST | `/api/sources/update` | 有効・無効の切り替え |
| POST | `/api/keyword/add` | 検索キーワードの追加 |
| POST | `/api/bookmark` | 保存 |
| POST | `/api/config` | 設定変更 |

静的ファイルは `os.path.realpath` で解決してから公開フォルダ配下か検証する。
正規化前に検証すると `/../../etc/passwd` が通る。
