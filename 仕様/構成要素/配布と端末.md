[仕様書.md](../../仕様書.md) の構成要素。**どこで動くか：macOS / Windows / Android / iOS / Fire と、5つ目の web（公開版）。**

## 4プラットフォーム構成

同じ画面と同じデータを、2つの収集エンジンで動かす。

```
                 共通（1文字も変えずに使う）
   ┌──────────────────────────────────────┐
   │  web/    UI 20モジュール・CSS・地図・音   530 KB │
   │  tables/ ソース106本・語彙367語・地名辞書  50 KB │
   └──────────────────────────────────────┘
         ↑                              ↑
   Python 収集エンジン            JavaScript 収集エンジン
   （デスクトップ）                  （モバイル）
   macOS / Windows                Android / iOS / Fire
```

図の数字は2026-09-26 数えたもの。数え方：モジュールは `droneradar/web/js/*.js` の本数、大きさは `git ls-files` の各ファイルのバイト数の合計（1 KB＝1024 バイト）、
ソースは `tables/sources.json` の `sources`、語彙は `tables/terms.json` の12の語群の語数の合計。

行数と大きさは2026-09-26 数えたもの（`wc -l core/*.js`・`wc -c`）。変わったのは `collector.js` だけ（129→194）。
**「Python との照合」の件数と 100% は未確認**——照合に使った台がリポジトリに無く、今は流し直せない。当時の記録のまま残す。

移植で判断が要った点を3つ。

**記事IDの採番を変えた。** ブラウザの `crypto.subtle` は非同期で、SHA-1 をそのまま使うと呼び出し側すべてが async に汚染される。IDは1台の収集内で安定して衝突しなければよいので、同期の FNV-1a 系に置き換えた。

**切り詰めは文字単位。** Python は文字数、JavaScript の `slice` は UTF-16 単位で数える。絵文字1個で2ずれる上、サロゲートペアを半分で切ると文字化けする。

**実体参照はセミコロン省略に対応。** 長いURLが途中で切れて `&amp` で終わることがあり、Python の `html.unescape` はこれを解釈する。

## 8.7 web を5つ目のOSとして

同じ `droneradar/web/` が2つの形で動く。`js/mode.js` が起動時に一度だけ
`/api/status` を叩いて、どちらに話しかけているかを決める。ホスト名では
判断しない——Mac 版はループバック・Bonjour名・LANアドレスと複数の名前で
到達し、公開先も動きうるので、名前で書いた規則は最初にどちらかが動いた
日に黙って壊れる。404 は曖昧でない。判定不能なら静的側に倒す
（読めるが書けない、の方が安全側）。

| | 公開版 | Mac 版 |
|---|---|---|
| 収集 | Actions が毎時07分 | アプリ起動中に15分ごと |
| 読み | `api/*.json` | `/api/*` を都度生成 |
| 保存済み | localStorage（端末ごと） | サーバ側 |
| ソース追加・手動収集 | **不可** | 可 |
| 画像 | 発行元へ直リンク | `/img?u=` プロキシ |

## web で実現できないこと

1. **書き込み全般**（ソース管理・手動収集・設定）。静的配信に POST の
   相手はいない。押すと「この画面は読むだけです」と出して、黙って
   失敗させない
2. **Reddit 系のソース**。Reddit はデータセンターIPに 429 を返し、
   Google News も Reddit を索引していないので代替経路が無い。
   定義は5本、2026-09-26 01:29Z の回では4本が 429（r/drones だけ通った）（2026-09-26 数えた）
3. **保存済み記事が端末ごと**。45日の保持期限からも守れない

## インストールできる形にする

`app.webmanifest` とアイコン（192/512）をビルド時に生成する。他の4ビルドは
自前のウィンドウとアイコンを持つのに web だけブラウザのタブで、**5つの中で
読者が実際に気づく差はそこだった**。iOS は manifest の display を読まないので
`apple-mobile-web-app-*` も併せて置く。

manifest を `web/` に置かずビルド時に書くのは、`start_url` と `scope` が
公開先からの相対で決まる一方、Mac 版は同じディレクトリを別の根から出すため。
