# DroneRadar — 地図のスポットライト

[仕様書.md](../../仕様書.md) の構成要素。**日本地図・世界地図で「どの地域の、どの記事を」ピコーンと出すか。**
ズームと地球儀の動きは [地球儀](地球儀.md)、地図とキャプションの寸法は [地図の配置とキャプション](地図の配置とキャプション.md)。

| | |
|---|---|
| 受け持つ | 地域の選び方（総当たり・全国の織り込み）、記事の鮮度、日本の記事の振り分け、ピンとバブルのアイコン |
| 受け持たない | viewBox のズーム・球の回転（[地球儀](地球儀.md)） |

## 地図のスポットライト（ピコーン）

7秒ごとに1地域を選び、ピンを打ってキャプションに記事を出す。選び方に
2つの欠陥があった。

**1. 同じ地域ばかり出る。** 「新着順に並べ、直近4回に出た地域は飛ばす」
という作りだった。1日に入る記事のうち **ロシア60件＋ウクライナ26件で
54%** を占めるので、4回の間隔は間隔にならない。5回に1回ロシアに戻り、
別の見出しで同じ戦争の話が出る——外から見れば「同じのばかり」。

履歴を伸ばしても解決しない。伸ばすと地域を使い切ってリセットし、
リセット先はまた同じ数地域になる。

そこで**地域の総当たり**に変えた。ニュースのある地域は、他の全地域が
一巡するまで2度目の順番が来ない。地域内では新着順に消費する。
ウクライナはニュースの量なりに出るが、1時間に4回は出なくなる。

一巡の目安：世界32地域で約3.7分、国内13地域で約1.5分。

**2. 昨日の記事が今日も出る。** 記事の保持は45日で、スポットライトは
その全部から選んでいた。最後のドローン記事が1週間前の地域は、順番が
来るたびにその1週間前の記事を出す。**48時間**より古い記事は選ばない
（対象地域が4未満なら7日、2未満なら14日まで広げる）。

GitHub のリポジトリも除外する。作者の所在で国が付いているだけで、
その土地について何も言っていない。



## 都道府県の分からない日本のニュース

日本の記事435件のうち、都道府県が付くのは312件。残り129件は
**どの県にも属さない**——防衛省の概算要求、全国販売の発表、制度そのもの。
点で指せる場所が無い。

そこで**地図全体をピコーンとさせる**。日本地図の巡回に「全国」という
1地域を足し、その順番では：

- 47都道府県すべてが同時に光る（位置で少しずつ遅らせ、波が渡るように）
- ピンは地図の中心から、地図の幅の6割まで広がる
- **カメラは引く。** 県の記事が寄るのと逆向きの同じ動作——主題が地図の
  どの部分よりも大きいので、地図の方が小さくなる。地図の外枠より22%広い
  viewBox（760→927）まで引き、3.2秒保って戻る。県のズームと同じ間合い
- **ピンは滋賀県から出す（半径は地図幅の92%＝699）。** 滋賀からの最遠点は
  北海道の北端で650、つまり地図幅の0.855倍。72%（547）では青森沖で止まり、
  「全国」を名乗るピンから北が漏れていた。少し多めに取って、波が海岸で
  死なずに越える。実測で47県すべてが半径内 「どこでもない」に
  正直な点は無いが、地図の箱の幾何中心は能登沖——海の上——で、恣意的以下
  だった。かといってリングを出さないと、全県点灯だけでは「ピコーン」に
  見えない。滋賀は本州の真ん中で、陸地
- **地図上にジャンルアイコンは置かない。** 点に置く印は「ここ」と言うが、
  この記事が地図全体に出ている理由は「ここ」が無いこと。ジャンルは
  キャプション側のアイコンが示す
- **前の県のズーム予約を取り消す。** 全国は zoomToRegion を呼ばないので、
  取り消す者が居なかった——全県が光っている間に大阪へ寄っていける状態
  だった
- 光るのは**その瞬間だけ（1.1秒）。** 明滅は塗りを置き換えず明るくする
  だけで、残りの6秒は県別の色分けが読める状態に戻る

これで世界地図から日本を完全に外せた（従来は2位・435件を占めていた）。

**「全国」は21都道府県と同格の1地域ではない。** 総当たりは、どれも同じ
種類の場所であるときに正しい。全国は場所ではなく「場所でないもの全部」で、
日本の記事の**29%**を占める。22分の1の順番＝4%では、3割近い区分が
4分に1回しか回らず、機能が切れているように見えた。

そこでシェアに応じて順番に織り込む（29%なら3地域ごとに1回）。上限は
3地域に1回で、地図が全国ばかりになるのを防ぐ。

実測：広島県 → 東京都 → 大阪府 → **全国**（47県同時点灯・ズームなし）。



## 世界地図に日本は要るか

日本は世界地図で **435件・ロシア(438)に次ぐ2位**。すぐ隣に日本地図が
あるのに、世界地図の日本の順番でも日本のニュースが出るのは重複だった。

ただし丸ごと外すと失うものがある。日本の435件のうち都道府県が付くのは
312件で、**残り129件はどの県にも属さない**——防衛省の概算要求、楽天の
提携、全国販売の発表、制度そのもの。日本地図には出しようがない記事なので、
世界地図から外すと**どちらの地図からも消える**。

そこで世界地図の日本の順番は、**都道府県が付いていない記事だけ**にした。
重複は無くなり、失うものも無い。

| | 変更前 | 変更後 |
|---|---:|---:|
| 世界地図の日本（48時間内） | 都道府県付きも含む | **全国レベル 25件のみ** |
| 世界の順位 | 2位 | **5位** |
| 日本地図 | 18地域 | 変更なし |

塗りとバブルは全件のまま。「世界のドローン報道のうち日本がどれだけか」は
それ自体が情報なので、変えるのは順番に出す記事だけ。


### ピンとバブルのアイコン

地図のピンだけは SVG 単位ではなく画面 px（26px）で大きさを決めている。
2枚の地図は viewBox の尺度が大きく違い、右列の幅も画面で変わるため、
SVG 単位で指定すると日本地図側が 5px になってしまう。

地図のバブルには常時アイコンを置かない。1つの地域に複数ジャンルの記事が
あっても最多の1つしか出せず、地域の性格を実際より断定してしまう。
スポットライト（ピン）は対象が1記事に確定しているので、そこでだけ出す。
